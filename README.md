
# ❤️ Heart Rate Anomaly Detection

Machine learning project for detecting statistically unusual patterns in heart-rate frequency-domain features.

## Model

- Algorithm: Isolation Forest
- Estimators: 200
- Contamination: 5%
- Features: 11 frequency-domain features

## Features

VLF, VLF_PCT, LF, LF_PCT, LF_NU, HF, HF_PCT, HF_NU, TP, LF_HF, HF_LF

 Disclaimer

This project performs statistical anomaly detection and is not a medical diagnostic system.
